# AP Cybersecurity

Course website: https://mrchristievp.github.io/AP-Cybersecurity/

A static directory of course notes and practice for five AP Cybersecurity units. No build, installation, or JavaScript is required.

## Add materials

Edit the relevant row in `index.html` (identified by `id="unit-1"` through `id="unit-5"`). Replace the dash in the Notes or Practice column with a link. Use relative paths for pages in this repository, or full URLs for separate sites.

Linux practice links to its existing site so it can be updated independently.

## Publish

GitHub Pages serves the root folder of the `main` branch. Upload changes to publish them automatically.

- `index.html`: course units and resource links
- `style.css`: layout and colors
- `favicon.svg`: site icon
- `.nojekyll`: static hosting

Original provider files and student information are not included. This is a classroom resource, not an official College Board website.
